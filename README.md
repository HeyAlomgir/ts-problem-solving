# Assignment 1: Problem Solving with TypeScript & OOP

## Overview

এই Repository-তে Programming Hero Level 2 Batch 8-এর Assignment 1-এর সমাধান রাখা হয়েছে।

এই Assignment-এর মূল উদ্দেশ্য হলো TypeScript-এর গুরুত্বপূর্ণ বিষয়গুলো অনুশীলন করা এবং Object-Oriented Programming (OOP) সম্পর্কে ধারণা অর্জন করা।

## Technologies Used

- TypeScript
- JavaScript
- Object-Oriented Programming (OOP)

## Assignment Problems

এই Assignment-এ মোট ৮টি Coding Problem সমাধান করা হয়েছে।

1. Optional Parameters এবং Default Value
2. Union Types এবং Type Narrowing
3. Readonly Tuple এবং Destructuring
4. Generic Function এবং Array
5. Interface এবং Array Filtering
6. Generic Constraints এবং `keyof`
7. Class, Inheritance এবং Access Modifiers
8. Promise এবং Asynchronous Function
